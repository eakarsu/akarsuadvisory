# Governed advisory workflow runbook

The production journey begins with a consented public advisory inquiry and ends with a provider-confirmed engagement kickoff. An analyst performs deterministic qualification, an advisor schedules and records discovery, an advisor authors a typed proposal, a different manager approves it, document and messaging providers generate/deliver it, the client accepts or declines through a single-use expiring decision token, and CRM confirms kickoff. Generated and generic-AI routes are development-only.

Install from lockfiles and run `./start.sh check`. Configure the database, strict JWT issuer/audience/secret, public tenant, public application URL, CORS allowlist, versioned 32-byte data key, provider webhook secrets, and fixed HTTPS provider URLs/tokens in the secret manager. Back up PostgreSQL and run `ALLOW_SCHEMA_MIGRATION=1 ./start.sh migrate` twice before release. Startup and container startup never install, seed, migrate, create databases, rewrite connection URLs, or kill unrelated processes.

Client identity/contact, discovery notes, proposals, and provider payloads are AES-256-GCM encrypted with tenant/case context. Queue views expose only a one-way client token. Provider jobs use stable keys, leases, retries/backoff, dead letters, fixed endpoints, and signed replay-protected callbacks. Monitor intake failures, qualification gaps, stage age, stale versions, approval separation, outbox age/leases/retries/dead letters, callback signatures/replays, decision-token expiry, CORS/auth failures, and readiness. Reconcile provider receipts before replay.

Backups must include encryption versions, identities, cases, immutable events, outbox jobs, and provider event IDs; restore tests must prove decryption and event counts. Key rotation requires reviewed re-encryption and reference verification before retirement. For suspected client-data exposure, disable identities/provider credentials, preserve evidence, rotate affected secrets, scope tenants/cases/fields/time, involve security/privacy/legal leadership, assess notification duties, and document containment.

Real calendar/document/messaging/CRM contracts, representative analyst/advisor/manager/client validation, proposal legal review, production SSO/MFA, privacy/security assessment, provider certification, backup restore, monitoring integrations, and incident approval remain external launch gates.
